# Earth Hydro — Р.ОС.НЕДРА

Тестовая автономная сборка корпоративного 3D-баннера с условной географией работ.

## Текущий состав

- `index.html` — входная страница и адаптация к макету сайта;
- `assets/` — готовые JS/CSS-сборки React/Three.js;
- `textures/` — локальные текстуры Земли;
- `geography.json` — география из согласованных KMZ-точек и дополнительно размещённые условные маркеры;
- `favicon.svg` — иконка.

Откройте тестовый адрес Cloudflare Pages после подключения репозитория. Для локального запуска подойдет обычный статический HTTP-сервер.

## Публикация в Cloudflare Pages — Git integration

1. Создайте **приватный** репозиторий GitHub и загрузите содержимое этой папки **в корень** репозитория.
2. Cloudflare Dashboard → **Workers & Pages** → **Create application** → **Pages** → **Connect to Git**.
3. Подключите GitHub и выберите нужный репозиторий.
4. Для текущей готовой статической сборки используйте: Framework preset `None`; Build command — оставить пустым; Build output directory — `/` или `.`, в зависимости от поля формы. Корневой файл должен быть `index.html`.
5. Для рабочего тестового проекта назначьте ветку `main`. Изменения в иных ветках можно проверять на отдельных Preview-ссылках. Не подключайте домен rosnedra72.ru до принятия баннера.

**Важно:** создавайте проект сразу с Git integration. Cloudflare не позволяет переводить существующий Direct Upload Pages-проект в Git integration.

## Конфиденциальность

Не добавляйте исходные KMZ/KML или таблицы с реальными координатами в GitHub и в сборку Cloudflare, даже если репозиторий приватный: тестовая страница доступна по публичному URL. Публичная карта — иллюстрация регионального присутствия. Для исходных KMZ используйте отдельный локальный рабочий архив вне Git и без размещения в публичном JavaScript.

## Проверка перед публикацией

- Земля отображается на компьютере и смартфоне;
- метки видны на передней стороне и исчезают на обратной;
- офисная точка Тюмени крупнее остальных, без отдельного знака;
- при наведении/касании показывается название компании и адрес;
- проверены масштабирование, анимации и производительность;
- отсутствуют настоящие координаты объектов;
- проверены внешние ссылки, доступность и браузерная консоль.

## Технический долг

Это **архивная compiled-only сборка**. Исходные React/Three.js-файлы (`src/`, `package.json`) здесь отсутствуют; восстановление редактируемого исходного проекта — отдельная задача. При небольших правках собранный JS неудобен и рискован. В идеале перенести исходный проект из Replit или переписать компонент Earth Globe в поддерживаемый исходный код.

Текущий пакет не содержит системы приватной загрузки KMZ и не должен позиционироваться как полностью проверенная финальная версия. Встроенное пояснение внизу баннера: точки и дуги условны.
