# Earth Hydro — корпоративный 3D-баннер Р.ОС.НЕДРА

Тестовая сборка для Cloudflare Pages. За основу визуального оформления взята согласованная композиция баннера действующего сайта rosnedra72.ru и предоставленный файл `index.php` с параметрами WebGL-глобуса.

## Содержимое

- `index.html` — точка входа статического сайта;
- `assets/` — собранные React/Three.js-модули и исходный CSS приложения;
- `banner-final.css` — единый адаптивный слой вёрстки баннера;
- `banner-final.js` — текст, счётчики, логотип, единая анимированная волна;
- `rosnedra-logo.svg` — официальный логотип из предоставленного изображения;
- `textures/` — локальные текстуры Земли;
- `geography.json` — только демонстрационные региональные зоны.

## География

Внутри WebGL-модуля отображаются **32 координаты** из предоставленного пользователем KMZ, а также дополнительные **условные** региональные маркеры. Все точки имеют одинаковую голубую гамму; Тюмень выделяется размером, при наведении появляется адрес офиса. Координаты из KMZ использованы с разрешения пользователя, без названий объектов.

**Внимание к конфиденциальности:** несмотря на отсутствие подписей, точные координаты 32 KMZ-точек теперь находятся в публично доступном клиентском JavaScript. Это необходимо учитывать перед переносом на основной сайт. Удаление таких координат требует отдельной очистки истории Git, а не только удаления из последней версии файлов. Если публичное размещение точных координат не одобрено компанией, нужно заменить их региональными схемами и очистить историю публикации.

## Cloudflare Pages

Подключено к репозиторию через Git. Для текущей сборки используйте Framework preset `None`, команду сборки оставьте пустой, Output directory `.`.

Параметр `?embed=1` скрывает дублирующую шапку, когда баннер встраивается в готовую страницу 1С-Битрикс (наличие подходящего контейнера и высоту iframe необходимо проверить при интеграции). Основной сайт не изменён.

## Проверка качества

- [x] В исходнике исправлена ориентация долготы (включая переход через ±180°);
- [x] Восстановлена тонкая атмосфера из предоставленного оригинального PHP-блока;
- [x] Убрано дублирование волн, оставлен один фоновый слой;
- [x] Географические точки и офис приведены к корпоративному цвету;
- [x] Заменены конфликтующие CSS-переопределения;
- [ ] Визуальная проверка реального WebGL-рендера на Cloudflare: **не подтверждена** — изолированный браузер в рабочей среде не предоставляет WebGL 2;
- [ ] Проверка реальной мобильной версии в браузере пользователя;
- [ ] Проверка корректности всех точек при вращении и при наведении.

## Поддерживаемость

Сохранён полный исходный React/Three.js-проект в отдельном локальном архиве `Earth_Hydro_v8_source.zip`, но текущий GitHub-проект построен из исторической собранной версии. Следующим техническим шагом следует перенести исправления в оригинальные `src/` файлы и выполнять воспроизводимую сборку через Vite, а не изменять минифицированный JS вручную.
