# Контрольный список — Earth Hydro / Cloudflare

1. Создать приватный репозиторий GitHub **earth-hydro-rosnedra**.
2. Загрузить *содержимое* архива в корень репозитория, не исходный файл KMZ.
3. В Cloudflare Pages выбрать **Connect to Git**, а не Direct Upload.
4. Выбрать репозиторий, ветку `main`, Framework `None`, Build command пусто, Output directory `.`.
5. После первого успешного развёртывания открыть выданный Cloudflare адрес `*.pages.dev` в Chrome и на телефоне.
6. Проверить точки на 3D-Земле, Тюмень, карточку с адресом, вращение, мобильный вид, ошибки консоли.
7. Замечания оформить в отдельной ветке GitHub, проверить Preview и лишь затем объединить с `main`.
8. Не подключать основной корпоративный домен до окончательного утверждения и проверки безопасности.

**Текущие ограничения:** код имеется как собранные assets без оригинального проекта React/Three.js; автоматический сквозной WebGL-тест не подтверждён. KMZ в эту публикацию не включён.
